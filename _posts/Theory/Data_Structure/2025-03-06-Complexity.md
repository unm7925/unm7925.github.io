# __시간복잡도와 공간복잡도 그리고 빅오(Big-o) 표기법__

너무 복잡하게 설명 및 정리할 생각이 없다.

간단하게 정의를 작성하고, 사용 법, 알아야 하는 이유 관련하여 설명할 것 이다.

## __복잡도__

복잡도란? <br>

바로 유추할 수 있 듯 얼마나 복잡한가? 를 나타내는 것이다. <br>
그렇다면 우리가 생각할 것은 복잡할수록 좋은 것 인가? 아니면 복잡하지 않을수록 좋은 것 인가? <br>
여기서 나타내는 복잡이란? <br>
막 뒤엉키고 뒤엉키는 그런 것을 나타내는 것이 아니라 양에 관련해서 설명하는 것 같다.<br>
즉 복잡도가 높다라는 것은 어떠한 특정 값이 높다 라는 것과 같다고 생각하면된다.<br>

### __(시간과 공간)복잡도__

여기서 특정 이란? 복잡도를 두 가지로 나눌 수 있는데 <br>
그것은 바로 `시간`복잡도와 `공간`복잡도로 나눌 수 있다. <br>
<br>
우리는 위에서 복잡도가 높다라는건 특정 값이 높다라고 했다. 그렇다면 시간복잡도와 공간복잡도는 이렇게 해석할 수 있다.<br>
시간이 얼마나 걸리는지, 공간을 얼마나 많이 차지하는지 라고 생각 할 수 있고, 시간이 얼마나 걸리는지에 관련하면 연산 횟수를 비롯하고, 공간은 메모리에 해당한다. 그리고 이 둘은 일반적으로 반비례하는 경우가 많다.<br>

우리가 직관적으로 알 수 있게 설명을 해보겠다. <br> <br>

지름이 1cm 인 바퀴와 지름이 10cm인 바퀴가 있다. <br>
이 바퀴들이 1m * pi 를 지나려면 지름이 1cm인 바퀴는 100바퀴 지름이 10cm인 바퀴는 10바퀴를 지나야 한다. <br>
대충 감이 오는가? 물론 지름이 1cm인 바퀴가 마구마구 빨리 돌아서 지름이 10cm인 바퀴보다 빠르게 갈 순 있다.<br>
하지만 결국 1cm 바퀴는 100바퀴 라는 횟수를 돌아야하고, 10cm 바퀴는 10바퀴를 돌아야한다.<br>
고로 반비례 하는 경우가 잦다. 아니면 반비례하는 경우가 아닌 것을 찾고싶다면 찾아보는 것도 권장한다. 나는 아직 그럴 생각이 없다. <br>


### 빅오(Big-O)표기법

그리고 위와 같은 복잡도를 나타내기 위해 빅오(Big-O)표기법을 사용한다.

직관적인 그래프로 보여주자면
![image](TimeComplexity.png)

<br>
<br>
또 표기법과 표현을 정리하면 <br>

| 빅오(Big-O) 표기법 |   표 현   |
| :----------------: | :-------: |
|        O(1)        |   상수    |
|      O(log n)      |   로그    |
|        O(n)        |   선형    |
|     O(n log n)     | 로그 선형 |
|       O(n^2)       |   다항    |
|       O(2^n)       |   지수    |

=> 2는 변하지 않는 특정 상수를 뜻 하는 것. <br>
=> n은 변해도 상관없는 특정 자연수를 뜻하는 것.

그리고 다른 정렬들과의 관계는 본 글에 대표이미지로 된 표와 같다.

# __알아야 하는 이유__

아니 다 알겠는데. 그럼 이걸 왜 알아야하냐? 라는 의문이 들 수 있다. <br>
당연히 연산횟수가 줄어들면 좋고, 메모리를 알잘딱으로 쓰면 좋은 것 알겠는데 그건 대충 코딩치면서 알지 않는가?<br>
그건 맞는 말이다 우리가 뭐 연산횟수가 느는걸 몰라서 반복문을 쓰는건가? 정렬을 쓰는건가? 아니다 알지만 쓰는 것 이다<br>
<br>
그럼에도 알아야 하는 이유는 내 개인적인 생각을 첨부해서 말하자면 <br>
우선 자세히 뜯어보면 알겠지만 기본적으론 코딩한 너만 알고 있다. 그리고 정확하게가 아니라 대강 알고 있을 것 이다.<br>
왜냐? 어떤 사람이 본인 코딩한걸 보지도 않고, 기억만으로 생각할 수 있겠는가? <br>
그리고 우리는 결국엔 협업을 해야하는 사람이고, 알고리즘 문제 뿐만 아니라 대형프로젝트나 그런 것들에 의해 생길 일들을 생각한다면 일단 표기를 해놓고, 점점 줄여나가야 하는 체크리스트를 작성하는 것이라 생각해야한다. <br>

또한 개인적인 이유는 <br>
알아야 하는 이유는 본인만의 체크리스트를 만들기 위함이다. <br>
처음부터 설계를 하고, 공부를 하고, 우리는 어떻든 간에 계속 공부를하고, 발전해나아가야 하는 사람으로써 당연한 것이라고 생각한다.<br>

3줄로 요약하자면
1. 표기한다면 규모가 늘어나도 문제없음
2. 표기한다면 남들도 자세히 보지 않아도 예측할 수 있음
3. 표기한다면 수정을 통해 본인의 성장을 확인할 수 있음
